# Специфікація SportEvents — варіант 20

## Межі системи
| Входить | Свідомо не входить |
|---|---|
| Створення учасників, стартів і реєстрацій | База даних та акаунти спортсменів |
| Внесення часу дистанції до мілісекунди | Фотофініш, GPS та зовнішні датчики |
| Вікові групи, місця, пошук, протокол | Командні чемпіонати і ліцензійні спортивні розряди |
| JSON-файл, журнал без персональних даних | Вебінтерфейс та права доступу |

## Словник домену
| Поняття | Ідентифікатор | Значення |
|---|---|---|
| Учасник | Participant | Людина, яка стартує |
| Дата народження | BirthDate | Дата без часу |
| Змагання | SportsEvent | Документ зі станом |
| Стан змагання | EventStatus | Planned, Open, Finished, Cancelled |
| Дистанція | DistanceMeters | Довжина маршруту в метрах |

| Час проходження | Elapsed | TimeSpan |
| Вікова група | AgeGroup | Junior / Adult / Masters |
| Правило віку | AgeRules | Група на дату старту |

| Журнал | IAuditLogger | Запис подій системи |

## Сценарії використання

### UC-01. Додати учасника
**Актор:** організатор. **Передумова:** запущено меню. **Основний перебіг:** обирає 1, указує унікальний додатний номер, ім'я, дату народження; система зберігає довідниковий запис. **Альтернатива А:** номер дублюється — збереження немає, виводиться пояснення. **Альтернатива Б:** дата народження пізніша за поточну — система відхиляє ввід. **Постумова:** новий учасник доступний для реєстрації.

### UC-02. Створити змагання
**Актор:** організатор. **Передумова:** доступне сховище. **Перебіг:** обирає 2, пише назву, дату та дистанцію; система присвоює номер і стан Planned. **Альтернатива А:** порожня назва — помилка вводу. **Альтернатива Б:** дистанція 0 чи менша — помилка вводу. **Постумова:** змагання є в JSON.

### UC-03. Зареєструвати учасника
**Актор:** організатор. **Передумова:** змагання має стан Open; учасник є у довіднику. **Перебіг:** обирає 4, вводить номер змагання й учасника; створюється EventRegistration. **Альтернатива А:** реєстрацію не відкрито — відмова. **Альтернатива Б:** учасник уже внесений або відсутній — відмова. **Постумова:** учасник отримує право на фінішний результат.

### UC-04. Внести результат
**Актор:** суддя. **Передумова:** стан Open, учасник зареєстрований. **Перебіг:** пункт 5, номер змагання, номер учасника та час `hh:mm:ss.fff`; результат записують у файл. **Альтернатива А:** час нульовий, від'ємний, >=24 год або точніший за мілісекунду — відмова. **Альтернатива Б:** результат внесено раніше — повторний запис заборонено. **Постумова:** є один FinishResult на пару старт/учасник.

### UC-05. Керувати станом змагання
**Актор:** організатор. **Передумова:** змагання існує. **Перебіг:** з Planned обирає 3 (Open); після результату обирає 6 (Finished). **Альтернатива А:** із Planned/Open можна обрати 7 (Cancelled). **Альтернатива Б:** повторне відкриття/завершення або скасування Finished відхиляється. **Постумова:** збережено лише дозволений перехід.

### UC-06. Знайти змагання
**Актор:** організатор. **Передумова:** хоча б одне змагання створено. **Перебіг:** пункт 8, підрядок назви, дата; показано збіги за обома критеріями. **Альтернатива А:** дата порожня — фільтрація лише за назвою. **Альтернатива Б:** немає збігів — порожній список, без зміни стану. **Постумова:** стан не змінено.

### UC-07. Сформувати протокол змагань
**Актор:** суддя. **Передумова:** стан Open або Finished. **Перебіг:** пункт 9, номер старту; система групує результати за віком, сортує час за зростанням і друкує місця. **Альтернатива А:** однаковий час — однакове місце, наступне місце пропускає число (1, 1, 3). **Альтернатива Б:** у Planned/Cancelled звіт заборонений. **Постумова:** показано протокол, дані не змінено.

## Таблиця рішень профільного правила
Вік визначається у повних роках **на дату старту**. Час — `TimeSpan`, значення має бути додатним, відображення `hh:mm:ss.fff`.

| Вік на день старту | Група | Час A та B | Результат |
|---|---|---|---|
| 0–17 | Junior | A менший | A вище в Junior |
| 18–39 | Adult | A менший | A вище в Adult |
| 40+ | Masters | A менший | A вище в Masters |
| будь-яка одна група | відповідна | A = B | однакове місце (1,1,3) |
| різні групи | різні | будь-які | місця обчислюються окремо |
| будь-яка | — | час <= 0, >=24 год або дробові частки мс | внесення відхилено |
| народився пізніше старту | — | будь-який | реєстрацію відхилено |
