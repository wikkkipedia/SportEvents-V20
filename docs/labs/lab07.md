# ЛР7: xUnit і TDD

Розрахункові тести: ElapsedTimePolicyTests (порожній, недопустимий,
два відрізки), RaceTimeInputTests (коректні і помилкові дані),
ResultTableTests (вікові групи, однакові часи, порожній список).

Дублери з наявної інфраструктури тестів: InMemoryRepository — fake;
FixedClock — stub. Для алгоритму часу зовнішні дублери не потрібні.

Цикл TDD реалізовано 3 окремими комітами:
1. test(lab07): ... — тест звертається до ще неіснуючого RaceTimeFormatter,
   тому цей етап очікувано не компілюватиметься;
2. feat(lab07): ... — додана реалізація;
3. refactor(lab07): ... — виділена перевірка тривалості.
