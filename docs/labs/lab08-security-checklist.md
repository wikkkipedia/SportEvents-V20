# ЛР8 — чекліст безпеки SportEvents

| Критерій | Статус локального аудиту | Підстава |
|---|---|---|
| 1. Валідація вводу | Реалізовано у RaceTimeInput, EventService | Приймаються типізовані значення |
| 2. Секрети не потрапили в Git | У файлах зразка не виявлено ключів | Не заміняє secrets scanning |
| 3. SQL-ін'єкції | Не застосовується | Немає SQL/БД |
| 4. Логування без чутливих даних | Ідентифікатори сценарію | Рев'ю FileAuditLogger |
| 5. Уразливості NuGet | Не перевірено | Треба dotnet list package --vulnerable |
| 6. Перевірка залежностей / CI | YAML додано, запуск не підтверджено | Потрібен GitHub Actions |
