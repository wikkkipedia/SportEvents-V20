# Реєстр технічного боргу ЛР №6

Оцінки часу та ставки **навчальні припущення**, а не фактичний облік. Умовна ставка 250 грн/год.

|№|Борг|Ризик|Пріоритет|Погашення, год|Умовно, грн|
|---|---|---|---|---:|---:|
|1|CultureInfo не зафіксовано в ToString("0.00")|різні десяткові роздільники|Високий|1.0|250|
|2|Describe() бере DateTime.Now замість IClock|нестабільні тести на межах року|Високий|1.5|375|
|3|ClientKind та State передаються як string|невідомі значення й опечатки|Середній|2.0|500|
|4|Успадковані публічні поля SportsParticipant, SportsResultLine|слабкі інваріанти|Середній|2.0|500|
|5|Публічна логіка Handle пише у приватний журнал та повертає звіт|зайві побічні ефекти|Середній|1.5|375|
|6|Припущення про ставку доставки 60 і кап 500 не мають доменної специфікації спортивної події|бізнес-невідповідність|Середній|2.5|625|

Не змінювати форматування сум та годинникову поведінку під виглядом рефакторингу: це змінить спостережуваний результат старого модуля. Потрібна окрема задача з новими тестами.
