## Онлайн-частина
- Приватний репозиторій: https://github.com/wikkkipedia/SportEvents-V20
- Основна гілка: main
- Робоча гілка для PR: feature/ci-pipeline
- GitHub Actions запускаються на pull_request до main.
- Для показу червоного CI потрібно запушити на GitHub коміт 475e8ea як верхівку PR; потім відправити виправлений стан 6a6ebd1 або новіший.
- Без підтвердженого workflow-дозволу реальні запуски Actions та PR **не підтверджені**. Після виконання дописати посилання на run і PR.

Сенс перевірки: CI не дозволяє непомічено зливати некоректний тест, а після виправлення зелений запуск дозволяє злиття.
