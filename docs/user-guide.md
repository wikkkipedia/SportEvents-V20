# Посібник користувача SportEvents

## Запуск
З кореня проєкту виконайте `dotnet run --project SportEvents.Console`. Після першого запуску створюється умовний довідник із 60 учасників, на екрані видно меню від 1 до 9 та 0 для виходу. Файли `data/events.json` і `data/audit.log` розташовані відносно робочої теки, з якої запущено команду.

## Приклад 1. Створити старт
```text
Ваш вибір: 2
Назва: Осінній забіг
Дата yyyy-MM-dd: 2026-11-05
Дистанція, м: 5000
Створено змагання #1
```

## Приклад 2. Відкрити старт і зареєструвати учасника
```text
Ваш вибір: 3
Номер змагання: 1
Ваш вибір: 4
Номер змагання: 1
Номер учасника: 1
```

## Приклад 3. Внести час
```text
Ваш вибір: 5
Номер змагання: 1
Номер учасника: 1
Час hh:mm:ss.fff: 00:24:18.250
```

## Приклад 4. Завершити і подивитися протокол
```text
Ваш вибір: 6
Номер змагання: 1
Ваш вибір: 9
Номер змагання: 1
```
У протоколі є вікова група, місце, номер, ім'я та час. Місця між різними віковими групами не порівнюються.

## Приклад 5. Знайти старт
```text
Ваш вибір: 8
Назва або частина (Enter — усі): осін
Дата yyyy-MM-dd (Enter — усі): 2026-11-05
```

Наведено **приклади очікуваного діалогу**, не скріншоти фактичного запуску; перевірка запуску потрібна окремо.

## Типові помилки
- «Потрібен стан Open» — спершу відкрийте реєстрацію (пункт 3).
- «Учасника вже зареєстровано» — не повторюйте запис; перевірте номер.
- «Спочатку зареєструйте учасника» — внесіть його пунктом 4.
- «Час повинен бути більшим за нуль» — введіть тривалість з додатним значенням.
- «Протокол доступний лише...» — відкрийте чи завершіть змагання.
- «Не вдалося прочитати або записати файл» — перевірте права доступу до теки data та правильність JSON.

## Резервна копія
Закрийте застосунок, скопіюйте `data/events.json` у безпечне місце. Для відновлення поверніть копію до початкової теки. Не редагуйте JSON посеред роботи застосунку.
