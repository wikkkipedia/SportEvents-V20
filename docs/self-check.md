# Самооцінка — без вигаданих результатів

«Так» означає перевірене за вихідним кодом; «частково» — написано, але зовнішній запуск/звіт ще потрібен.

| № | Пункт | Оцінка | Чого бракує |
|---|---|---|---|
| 1 | Release без попереджень | частково | Потрібен фактичний `dotnet build` |
| 2 | XML-документація публічного API | частково | Перевірити діагностику CS1591 |
| 3 | Типи дат, часу, грошей | так | Грошових розрахунків у цьому варіанті немає |
| 4 | Немає магічних чисел | частково | Потрібен огляд констант, особливо меж віку |
| 5 | Найдовший метод до 30 логічних рядків | частково | Звірити методи та розділити великі |
| 6 | Максимальна CC до 8 | частково | Потрібен аналізатор/вимірювання |
| 7 | Вкладеність до 3 | частково | Потрібна машинна перевірка |
| 8 | Розрахунки без побічних ефектів | так | AgeRules і RankingPolicy — чисті від файлових побічних ефектів |
| 9 | Клас має чітку відповідальність | так | Перевірено за структурою |
| 10 | Залежності через конструктор | так | EventService має 4 підмінні залежності |
| 11 | Нове правило без зміни клієнта | так | IResultRanking |
| 12 | Барикада валідації | частково | Валідація на вході сервісу є; ввід консолі спрощений |
| 13 | Немає порожнього catch | так | Перевірено за вихідним кодом |
| 14 | Журнал без персональних даних | так | Записуються коди та номери |
| 15 | Немає дублювань і закоментованого коду | частково | Потрібен аналіз клонів |
| 16 | Не менше 25 зелених тестів | частково | Тести написані; виконання не підтверджене |
| 17 | Рядкове покриття >=70% | ні | Не виміряне, SDK недоступний |
| 18 | Непокриті гілки пояснено | ні | Потрібен реальний звіт про покриття |
| 19 | >=25 комітів за >=6 днів | ні | Вихідна історія не надана, не можна імітувати |
| 20 | README і відсутність секретів | частково | README є, Git-репозиторій ще потрібно опублікувати |

**Сума перевірених «так»: 7/20 (35%)**. Не варто оцінювати продукт вище, ніж підтверджено вимірюваннями.

## Резерв під перевірку непокритих гілок
Після `dotnet test ... -p:CollectCoverage=true` занесіть із Cobertura мінімум п'ять фактично непокритих гілок (файл, номер рядка, причина, рішення). Не заповнюйте цей розділ вигаданими адресами чи процентами.
