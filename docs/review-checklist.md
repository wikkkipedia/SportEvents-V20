## Чекліст огляду коду

- [ ] Чи одна зміна вирішує одну задачу?
- [ ] Чи пояснює назва методу його дію?
- [ ] Чи не приховано зміну стану у Get-методі?
- [ ] Чи всі часові величини мають правильні одиниці?
- [ ] Чи визначають вік саме на дату змагання?
- [ ] Чи правильно оброблено рівний час?
- [ ] Чи не порівнюються місця з різних груп?
- [ ] Чи відхиляється повторна реєстрація?
- [ ] Чи не записуються особисті дані в журнал?
- [ ] Чи названі причини відмови зрозуміло?
- [ ] Чи є тести для нової гілки?
- [ ] Чи є тест для нуля та межі?
- [ ] Чи не змінився публічний контракт непомітно?
- [ ] Чи не створена залежність Domain -> Infrastructure?
- [ ] Чи читається код без переходів між 5 методами?
- [ ] Чи збережено стару поведінку при рефакторингу?
- [ ] Чи не виносяться секрети у JSON/лог?
- [ ] Чи можна відкотити одну зміну окремим комітом?

Зауваження стосуються коду, не автора, та містять конкретну дію.
